# `docs`

Documentación del repositorio (no el Plan Maestro, que vive fuera del repo
en `Docs/Plan_Maestro/`). Se completa a medida que cada fase la necesita:

- `architecture.md`, `environments.md`, `deployment.md` — desde F3.
- `database.md`, `design-system.md`, `security.md` y una entrada por
  dominio (`clientes`, `empleados`, etc.) — desde F4 en adelante, con cada
  feature.
- `runbook-produccion.md` — desde F20.
- `adr/` — decisiones de arquitectura tomadas durante la implementación
  (distintas de los ADR del Plan Maestro).

Carpeta vacía hasta F3.
