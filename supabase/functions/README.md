# `supabase/functions`

Una única Edge Function del proyecto: `admin-users` (Deno), con las
acciones administrativas que necesitan la `service_role` (crear usuario,
resetear contraseña, desactivar, etc. — `06_API.md` sección 2.1). Se
despliega con `supabase functions deploy admin-users`.

Carpeta vacía hasta F7 (USERS-001).
